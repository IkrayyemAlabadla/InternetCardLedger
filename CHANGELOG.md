# Changelog

- Added Arabic RTL onboarding for MAIN and SECONDARY phones.
- Added offline Room storage for customers, sales, payments, and synchronization metadata.
- Added customer and sales record creation, viewing, editing, search, and safe deletion.
- Added dashboard summaries, recent activity, and filtered history.
